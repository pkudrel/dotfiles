# Registry values set by the install step scripts/75-appearance.ps1 (DWORD, current user; the key is created when
# missing, a value is written only when it differs). One per line:  <registry path> | <value name> | <number>
# The animation switches themselves (window minimize / maximize off; menus, lists, tooltips on) are set in the step with
# SystemParametersInfo, which applies them at once. Transparency, accent colour and the rest of the taskbar
# (widgets, task view, pinned apps) are not touched.

# Taskbar animations (not covered by the SystemParametersInfo switches)
HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced      | TaskbarAnimations    | 1

# Visual effects "Custom": Windows does not switch the effects back (e.g. to "Adjust for best performance")
HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\VisualEffects | VisualFXSetting      | 3

# Colours: Windows dark, apps light (Settings shows the mode "Custom")
HKCU:\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize     | SystemUsesLightTheme | 0
HKCU:\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize     | AppsUseLightTheme    | 1

# Taskbar aligned left (1 = centre); search as an icon (0 hidden, 1 icon, 2 box, 3 icon and label)
HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced      | TaskbarAl            | 0
HKCU:\Software\Microsoft\Windows\CurrentVersion\Search                 | SearchboxTaskbarMode | 1
